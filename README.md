# FuelWise AI — Smart Fuel Cost Estimator & Trip Planner

A beginner-friendly Flask web application that calculates fuel cost, saves trip estimates, shows charts, and provides practical fuel-saving tips. Browser voice recognition can fill in the three numeric fields; browser text-to-speech reads the result aloud.

## Features in this starter version
- Fuel-cost calculation using distance, mileage, and price per litre
- One-way and round-trip estimates
- Trip history stored in a database
- Cost and distance charts using Chart.js
- Rule-based travel tips (the initial AI-style recommendation module)
- Browser voice input and text-to-speech
- Responsive layout for desktop and mobile
- SQLite works out of the box; optional MySQL configuration

## Calculation
- Total distance = one-way distance × 2 for a round trip, otherwise one-way distance
- Fuel required (litres) = total distance ÷ mileage (km/L)
- Estimated fuel cost = fuel required × fuel price per litre
- Cost per km = estimated fuel cost ÷ total distance

Example: 240 km, 15 km/L, ₹105/L → 16 litres and ₹1,680 one way. A round trip doubles distance, fuel, and cost.

## Requirements
- Python 3.10 or newer
- pip
- A modern browser
- Optional: MySQL Server for database practice

## Run locally (Windows)
1. Extract this ZIP.
2. Open the project folder in VS Code.
3. Open Terminal in that folder.
4. Create a virtual environment:
   ```bash
   py -m venv .venv
   .venv\\Scripts\\activate
   ```
5. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
6. Start the app:
   ```bash
   python app.py
   ```
7. Open `http://127.0.0.1:5000` in your browser.

The SQLite database file is created automatically on first run.

## Use MySQL instead of SQLite
1. Create a database and a dedicated user in MySQL:
   ```sql
   CREATE DATABASE fuel_estimator CHARACTER SET utf8mb4;
   CREATE USER 'fuel_user'@'localhost' IDENTIFIED BY 'choose_a_strong_password';
   GRANT ALL PRIVILEGES ON fuel_estimator.* TO 'fuel_user'@'localhost';
   FLUSH PRIVILEGES;
   ```
2. In your terminal, set the connection URL (replace the password):
   ```powershell
   $env:DATABASE_URL="mysql+pymysql://fuel_user:choose_a_strong_password@localhost/fuel_estimator"
   ```
3. Run `python app.py`. Tables are created automatically.

Do not commit real passwords or secret keys to GitHub. Use environment variables.

## Important limitations
- This starter asks the user to enter route distance. It does not yet call a maps/directions API or retrieve live fuel prices.
- The tips are rule-based, not generated by a live LLM. This makes the project work without an API key and avoids unexpected API charges.
- Voice input availability varies by browser and microphone permissions. Check the recognised numbers before calculating.
- The “Electric” option currently uses the same distance/mileage/price formula, so it should be treated as a generic manual energy-cost estimate, not an accurate EV model. A future enhancement should calculate kWh and electricity tariff separately.
- This is a learning project, not a source of guaranteed travel cost or safety advice.
